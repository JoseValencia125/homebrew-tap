# Homebrew tap for Agents Pixel Dungeon

[Agents Pixel Dungeon](https://github.com/JoseValencia125/agents-pixel-dungeon) is a native pixel-art guild for your live [Herdr](https://herdr.dev) coding agents.

```sh
brew install --cask josevalencia125/tap/agents-pixel-dungeon
```

The cask installs the signed and notarized macOS app (Apple silicon, macOS 13 or later) and puts the guild's command line, `agents-pixel-dungeon-guild`, on your PATH. It is updated by the app's release workflow on every release.
